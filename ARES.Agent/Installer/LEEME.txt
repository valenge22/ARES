ARES AGENT v1.0
================

Este programa debe instalarse únicamente en equipos propios o con autorización.

INSTALACIÓN
1. Descomprimí el archivo ZIP completo.
2. Hacé doble clic en INSTALAR.bat.
3. Ingresá la clave proporcionada por el administrador. La dirección del servidor
   https://ares-3bic.onrender.com ya está configurada.
4. Aceptá el permiso de administrador.
5. El escudo de ARES aparecerá junto al reloj de Windows.

El instalador copia la aplicación en Archivos de programa y configura el inicio
automático al ingresar a Windows. Sólo realiza conexiones HTTPS salientes: no abre
puertos de entrada en la computadora monitoreada.
Por seguridad operativa, el agente no puede cerrarse desde su ícono. Para retirarlo,
un administrador debe ejecutar el desinstalador incluido.

DESINSTALACIÓN
Ejecutá DESINSTALAR.bat desde este mismo paquete. Windows solicitará permisos de
administrador y luego la contraseña exclusiva de desinstalación.
La contraseña es fija para todos los agentes de este paquete y fue definida por
el administrador al generar la versión. No se solicita durante la instalación.

REQUISITOS
Windows 10/11 de 64 bits. No necesita instalar .NET por separado.
