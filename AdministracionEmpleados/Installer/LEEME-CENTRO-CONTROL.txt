ARES CENTRO DE CONTROL
======================

1. Descomprimí el ZIP completo.
2. Ejecutá INSTALAR-CENTRO-CONTROL.bat.
3. La aplicación se abrirá y se crearán accesos directos.
4. En Configuración, ingresá la misma clave ARES_API_KEY usada en Render.

El programa se instala para el usuario actual en:
%LocalAppData%\Programs\ARES Centro de Control

No necesita instalar .NET por separado.

Para quitarlo, ejecutá DESINSTALAR-CENTRO-CONTROL.bat desde este paquete.
