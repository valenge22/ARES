ARES CENTRO DE CONTROL
======================

1. Ejecutá ARES-Centro-Control-Setup.exe.
2. Seguí el asistente gráfico de instalación.
3. Iniciá sesión con tu correo y contraseña de ARES.

El programa se instala para el usuario actual en:
%LocalAppData%\Programs\ARES Centro de Control

No necesita instalar .NET por separado.

Para quitarlo, usá Configuración de Windows > Aplicaciones instaladas.
